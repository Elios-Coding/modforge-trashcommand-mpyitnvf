# TrashCommand

Server-side Fabric mod that keeps Hardcore flag/hearts while optionally allowing difficulty, gamemode, commands, and gamerule changes via config, plus configurable death behavior.

Generated by **ModForge AI**.

- Minecraft: `1.21.11`
- Loader: Fabric `0.18.4`
- Fabric API: `0.141.4+1.21.11`

## Build

```bash
./gradlew build
```

The compiled `.jar` will be placed in `build/libs/`. GitHub Actions builds it automatically on push and publishes it to Releases.
